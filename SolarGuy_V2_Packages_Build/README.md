# Solar Guy Electrical Services V2

Static GitHub Pages build for solarguy.com.ng.

## Deploy
1. Upload/push the contents of this folder to the repository root.
2. Enable GitHub Pages from the repository settings.
3. Keep `CNAME` at the repository root for the custom domain.
4. Replace illustrative/AI visuals and any reference commercial details with verified final content before launch.

## Package architecture
Packages replaces the old Products catalogue. Package pages use reference/request-quote pricing and consultation-led commercial systems.
